# ML Access Control System

A Java-based mini system that simulates role-based access control for Machine Learning models.

## Features

- Admin full access
- Data scientist role validation
- Classification and regression model permissions
- Restricted access handling
- Basic role-based security simulation

  ## Technologies Used

  - Java
- Conditional logic
- Role-based access control

  ## Example Output

  You can use classification models!

  ## Learning Purpose

This project focuses on practicing Java backend logic, access control systems, and structured programming concepts applied to Machine Learning environments.
